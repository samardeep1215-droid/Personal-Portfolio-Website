# Samardeep Singh — Personal Portfolio Website

A responsive personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Sections
- Hero / introduction
- Profile summary
- Education timeline
- Projects (HoopStats, CourtBook, Expense Tracker, Portfolio)
- Technical skills
- Achievements & certifications
- Contact

## Run locally
Open `index.html` in a browser, or serve it:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Deploy
Deploy on [Vercel](https://vercel.com) as a static site.
